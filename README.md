# ☕ Shandoz Cafe Website

Website resmi untuk **Shandoz Cafe & Coffee Bar**, dibuat menggunakan HTML, CSS, dan JavaScript.

## 🌐 Live Website
https://shandoz.github.io/

## 📖 Deskripsi
Shandoz Cafe adalah coffee shop dengan suasana gelap elegan, musik santai, dan kopi berkualitas.  
Website ini menampilkan:
- Halaman utama (Landing Page)
- Menu kopi dan makanan
- Tombol musik
- Tampilan responsif untuk HP

## 📁 Struktur Folder
- `index.html` – Halaman utama
- `menu.html` – Halaman menu
- `styles.css` – Styling untuk website
- `script.js` – Logika musik dan interaksi
- `assets/` – Gambar dan file audio

## 🚀 Fitur
- Desain modern bertema dark cafe  
- Background musik yang dapat di-toggle  
- Animasi halus  
- Navigasi cepat  
- Section Best Seller, About, Contact, dan Footer

## 🛠️ Teknologi
- HTML5  
- CSS3  
- JavaScript  
- GitHub Pages (Hosting)
